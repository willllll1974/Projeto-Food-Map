# ADR-001 — Abordagem adotada para a interface web

## Contexto

Durante o desenvolvimento do FoodMap, foi preciso definir como seria estruturada e desenvolvida a interface web da aplicação.

A equipe avaliou a utilização do padrão MVC e também considerou o uso do React para a construção da interface.

## Decisão

A equipe decidiu utilizar React na construção da interface web do FoodMap.

A escolha foi feita porque a equipe considerou que o React oferecia maior flexibilidade para desenvolver a interface que havia sido idealizada para o projeto, além de contar com uma quantidade maior de bibliotecas e referências que poderiam auxiliar no desenvolvimento.

## Alternativa descartada

A utilização do padrão MVC foi descartada para a construção da interface web.

Compreendemos que essa abordagem não atenderia tão bem à estrutura e à experiência de interface que havia sido idealizada para o FoodMap.

## Consequência

A utilização do React permitiu que a equipe desenvolvesse a interface de acordo com a proposta visual anteriormente visada, aproveitando bibliotecas e referências disponíveis para auxiliar na implementação.
