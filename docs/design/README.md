# Caderno de Design — FoodMap

## Objetivo

Este Caderno de Design registra as principais decisões técnicas e arquiteturais tomadas pela equipe durante o desenvolvimento do projeto FoodMap.

Cada decisão é registrada em um ADR (Architecture Decision Record), contendo:

1. Contexto
2. Decisão
3. Alternativa descartada
4. Consequência
5. Commit

## ADRs

Os ADRs deste projeto serão organizados nesta pasta e documentarão as decisões de arquitetura, tecnologias, integração entre componentes e regras de implementação consideradas relevantes para o desenvolvimento.

## Organização

Os documentos seguem o formato:

`ADR-NNN-titulo-da-decisao.md`

Exemplo:

`ADR-001-arquitetura-do-sistema.md`
