# Caderno de Design — FoodMap

## Objetivo

Este Caderno de Design registra as principais decisões técnicas e arquiteturais tomadas pela equipe durante o desenvolvimento do projeto FoodMap.

Cada decisão é documentada em um ADR (Architecture Decision Record), permitindo registrar o contexto da decisão, as alternativas consideradas e suas consequências para o projeto.

Cada ADR contém:

1. Contexto
2. Decisão
3. Alternativa descartada
4. Consequência
5. Commit relacionado

## ADRs

Atualmente, o Caderno de Design possui 7 ADRs, que documentam decisões relevantes relacionadas à arquitetura, tecnologias utilizadas, integração entre componentes e organização dos dados do sistema.

Os documentos estão organizados nesta pasta e seguem uma numeração sequencial para facilitar sua identificação e consulta.

## Organização

Os documentos seguem o formato:

`ADR-NNN-titulo-da-decisao.md`

Exemplo:

`ADR-001-arquitetura-do-sistema.md`

As ADRs são numeradas de acordo com a ordem em que as decisões foram registradas no Caderno de Design.
